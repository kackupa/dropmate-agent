# Notice

DarkDrop Agents is an MCP/API integration layer for DarkDrop.

It depends on and adapts client-side DarkDrop logic for:

- claim-code encoding/decoding
- DarkDrop cryptographic payload generation
- proof generation
- relayer create/claim/withdraw flows

Upstream DarkDrop repository:

https://github.com/hitman-kai/darkdropv4

This repository should not be presented as an official DarkDrop project unless the DarkDrop maintainer agrees.
